   - #117は#101で成立した会話内合流をそのまま継続した結果であり、#117単独の新しいmovement失敗ではない。

3. **#156 / #170は「ペア会話文脈とglobal world_stateの差」として分離する。**
   - #156 Daphne×Campanula：このペアの会話ではDaphneは最初から図書館にいて、ペア内で移動していない。一方、別ペアDaphne×Anemoneの#150でDaphneはglobal world_state上カフェへ移動。その後#156で古いペア会話を続けたため、ペア内では図書館のまま。

花の名を持つ天使たちが暮らす街。

住人同士の日常的な挨拶では「お疲れ様」を多用せず、基本的には「ごきげんよう」を使う。親しい間柄では「どうしてた？」「今、少しいい？」など、挨拶を省いて自然に話しかけることもある。

会話の話題や展開は毎回同じ形にせず、それぞれの住人の性格や興味、その時の気分や居場所に合わせて自然に変化する。

## 能力

### 鐘の知らせ

- **id**：`bell_notice`
- **description**：これから何かが起こりそうなとき、その兆しを鐘の音として感じ取る能力。何が起こるのかまでは分からないが、響き方の違いから、喜ばしいことや異変、誰かの訪れなどをぼんやり察することができる。

```js
function activate(world_state, char_id, partner_id) {
    return char_name(char_id) + " はどこからともなく響く鐘の音に耳を澄ませ、何かが訪れる兆しを感じ取った。";
}
```

### 夢渡り

- **id**：`dream_walking`
- **description**：眠っている誰かの夢に入り、その人が見ている夢の中を歩くことができる能力。夢には記憶や感情、空想が混ざっているため、そこで見聞きしたことが現実の事実とは限らない。

```js
function activate(world_state, char_id, partner_id) {
    return char_name(char_id) + " は静かに夢の境界を越え、誰かの夢の中へと足を踏み入れた。";
}
```

### 花結び

- **id**：`flower_bond`
- **description**：人と人のあいだにある縁や親しさを、花が結ばれるような感覚として感じ取る能力。相手の気持ちを無理に変えるものではなく、すでにある縁や、これから育ちそうなつながりをそっと見つけやすくする。

```js
function activate(world_state, char_id, partner_id) {
    return char_name(char_id) + " は二人のあいだにある縁を感じ取り、まだ小さなつながりをそっと見つけた。";
}
```

### 花占い

- **id**：`flower_divination`
- **description**：花びらや花の様子から、これから起こりそうな出来事や選択の兆しを読み取る能力。結果はあくまで可能性のひとつで、未来を決めつけるものではない。

```js
function activate(world_state, char_id, partner_id) {
    return char_name(char_id) + " は花にそっと触れ、その様子からこれから訪れるかもしれない出来事の兆しを読み取った。";
}
```

### 忘れ灯

- **id**：`forgotten_light`
- **description**：忘れられかけた記憶や、心の奥に沈んでいる出来事の断片を、小さな灯りのように浮かび上がらせる能力。思い出せるのは断片だけで、失われた記憶を完全に復元することはできない。

```js
function activate(world_state, char_id, partner_id) {
    return char_name(char_id) + " は小さな灯りをともして、忘れられかけた記憶の断片を静かに浮かび上がらせた。";
}
```

### 光紡ぎ

- **id**：`light_weaving`
- **description**：光を糸のように紡ぎ、小さな飾りや花、景色のような形を作り出す能力。作られたものは本物ではなく、時間が経つと淡くほどけるように消えていく。

```js
function activate(world_state, char_id, partner_id) {
    return char_name(char_id) + " は光を細い糸のように紡ぎ、きらめく小さな形を作り出した。";
}
```

### 星詠み

- **id**：`star_reading`
- **description**：星の並びや夜空の変化から、これから起こりそうな出来事の兆しや可能性を読み取る能力。未来を確定させるものではなく、あくまでいくつかある可能性のひとつとして示される。

```js
function activate(world_state, char_id, partner_id) {
    return char_name(char_id) + " は夜空を見上げ、星の並びからこれから訪れるかもしれない出来事の兆しを読み取った。";
}
```

### 風囁やき

- **id**：`wind_whisper`
- **description**：風に乗った声や気配を拾い、少し離れた場所で交わされた話や出来事の断片を感じ取る能力。聞こえる内容は断片的で、必ずしも完全に正しいとは限らない。

```js
function activate(world_state, char_id, partner_id) {
    return char_name(char_id) + " は風に耳を澄ませ、遠くから運ばれてくる声や気配の断片を聞き取った。";
}
```

### 万華鏡

- **description**：エリュシオンの外にある世界の景色を、万華鏡を覗くように垣間見る能力。人間界やまだ知らない場所が映ることもあるが、見える場所や時間を自由に選ぶことはできない。

function activate(world_state, char_id, partner_id) {
