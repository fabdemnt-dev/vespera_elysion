# 観察記録Markdown（周別正本）

このフォルダ内の周別Markdownファイルが、エリュシオン観察記録（会話本文・世界状態・出来事などの記録）の**正本**です。旧ルート直下の単一ファイル`elysion_observation_unified.md`は、この周別正本への移行完了に伴って削除されました。

## 運用ルール

- **完走済みの周のファイルは、原則として編集しません。** 誤字修正など軽微な訂正が必要な場合を除き、本文の移動・並び替え・書き換えは行いません。
- **新しい周は、開始時点から周番号を含むファイル名で作成し、運用範囲が確定した時点の実採番レンジをファイル名に使います。** 通常の36組一巡だけでなく、対象限定運用では実際に記録した範囲を採用します。
- 周または限定運用が完了したら、このREADMEの表の状態を「完了」に更新します。会話の継続／終了分類は`conversation_status.md`を最新正本とします。
- **継続対象の組み合わせが複数周にわたって変化しない場合、1周＝1ファイルに固定する必要はありません。** 同じ継続対象構成が続く間は、複数周分をまとめた範囲（例：`#327-350_round21-32.md`のような複数周まとめファイル）として最初から作成してよいものとします。すでに作成済みの21〜41周目の個別ファイルは、この方針変更後も遡って統合・改名しません（完走済みファイルは編集しないルールを優先）。今後、継続対象の構成が変わった時点で区切りとし、新しいまとめ方を選び直します。
